# repo-bootstrap

[English](README.en.md)

> GitHub リポジトリを安全な標準構成で作る AI エージェント向けのスキル

## 概要

新しい GitHub リポジトリを、README・AGENTS・SECURITY・CONTRIBUTING・CI・Dependabot と GitHub のセキュリティ設定を備えた標準構成で作る、AI エージェント向けのスキルです。文書の言語（日本語・英語・日本語が主の日英併記・英語が主の英日併記）と公開範囲（Public・Private）を選べ、個人の GitHub Free で使えない機能は代替と制約を報告します。スキル本体は skills/repo-bootstrap にあり、Agent Skills の形式（SKILL.md）に対応したエージェントのスキル用フォルダ（Claude Code は ~/.claude/skills/、Codex は ~/.agents/skills/）にコピーして使います。このリポジトリ自体も、このスキルで作りました。
